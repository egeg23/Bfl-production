# BFL Production — контрактное юридическое производство БФЛ

Проект B2B-продукта «внешнее юридическое производство по банкротству физических лиц (БФЛ)»
для юридических компаний-партнёров. Инициатор — СРО арбитражных управляющих «ПроРешения»
([sro-proresheniya.ru](https://sro-proresheniya.ru/)). Этот репозиторий — рабочее пространство
руководителя продукта / лидера проекта: план запуска, исследование рынка и регуляторики,
экономика, дорожная карта, IT-контур.

## Суть модели (из описания продукта)

Юрфирма привлекает клиента и продаёт ему БФЛ → передаёт дело в нашу систему → мы ведём дело по
производственной цепочке (документы, юридические этапы, взаимодействие с финансовым управляющим,
сроки, качество, статусы, отчётность) → партнёр видит статус, сроки и результат.

Четыре слоя конечной конфигурации: продуктовая модель · производственный контур ·
финансовая модель · управленческий и цифровой контур.
