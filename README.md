# BFL Production — контрактное юридическое производство БФЛ

Проект B2B-продукта «внешнее юридическое производство по банкротству физических лиц (БФЛ)»
для юридических компаний-партнёров. Инициатор — СРО арбитражных управляющих «ПроРешения»
([sro-proresheniya.ru](https://sro-proresheniya.ru/)). Этот репозиторий — рабочее пространство
руководителя продукта / лидера проекта: план запуска, исследование рынка и регуляторики,
экономика, дорожная карта, IT-контур.

## Суть модели

Юрфирма привлекает клиента и продаёт ему БФЛ → передаёт дело в нашу систему → мы ведём дело по
производственной цепочке (документы, юридические этапы, сроки, качество, статусы, отчётность) →
партнёр видит статус, сроки и результат. Четыре слоя конфигурации: продуктовая модель ·
производственный контур · финансовая модель · управленческий и цифровой контур.

## Правила

- Русский — документы и планы; английский — код, имена файлов, коммиты.
- Никаких секретов и персональных данных должников в репозитории.
- Каждая цифра в документах — со ссылкой на источник или пометкой «оценка/допущение».
- `docs/SOURCES.md` не редактируется вручную: `python3 scripts/build_sources.py`.
- Шпаргалка пересобирается из `docs/cheatsheet/*.json`: `python3 scripts/build_cheatsheet.py`.
