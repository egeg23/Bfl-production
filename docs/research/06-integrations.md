# 06. Карта интеграций и источников данных цифрового контура

**Дата:** 2026-09-08 · **Для:** раздел 10 и п. 3.4 плана (`docs/PLAN.md`) · **Версия:** 1.0
**Метод:** ~35 поисковых запросов, ~25 прочитанных страниц (официальные сайты, документация, тарифы). Страницы fedresurs.ru (спецификации), fssp.gov.ru, download.fedresurs.ru, partners.gosuslugi.ru **не открылись через прокси** (HTTP 503/403/410) — по ним использованы выдержки поисковой выдачи, помечено «(по выдаче)». Цены — как опубликованы поставщиком на дату чтения; «оценка» — наш расчёт; «не найдено» — данных в открытых источниках нет.

---

## 1. Главные выводы

1. **Официальных API для юрфирмы почти нет.** Подача в «Мой арбитр» — только вручную под ЕСИА-учёткой юриста; API ФССП закрыт с 2022 г. (на 08.09.2026 страница описания отдаёт HTTP 410); Цифровой профиль и СМЭВ открыты лишь банкам, страховым, МФО, операторам связи; Открытые API Банка России отложены (октябрь 2025). Контур строится на **чтении публичных источников (КАД, ЕФРСБ) + структурированном ручном вводе в точках передачи**.
2. **Два публичных источника закрывают ~70 % статусной модели:** КАД — события суда (принято / без движения / заседания / акты), ЕФРСБ — события ФУ (введение процедуры, публикации, торги, отчёт, завершение). Производство видит ход дела **без интеграции с ПО финансового управляющего** — это техническая реализация «китайской стены» (раздел 4 плана).
3. **Покупать, а не парсить.** kad.arbitr.ru защищён антиботом (WASM-отпечатки), ЕФРСБ банит IP на час. Обёртки стоят 4–5 ₽ за запрос (you-right: 1 000 запросов — 4 900 ₽/мес, 10 000 — 46 000 ₽/мес): при 500 активных делах ≈ 25–50 тыс. ₽/мес (оценка) — дешевле разработчика на поддержку парсеров.
4. **Официальный REST ЕФРСБ есть** (с 15.04.2024; заявка bhelp@interfax.ru, тест 2 недели, токен, ≤ 8 одновременных запросов с IP — по выдаче), цена «по запросу». Запросить в фазе 0.
5. **Документы должника — только через должника:** 2-НДФЛ, СФР, ЕГРН (третьим лицам с 01.03.2023 без ФИО собственника), ГИБДД, выписки банков, кредитный отчёт (2 бесплатных/год) получаются в Госуслугах/ЛК. Инструмент производства — чек-лист + кабинет должника + OCR, а не API.
6. **Деньги и подписи — готовые продукты:** сплит и номинальные счета (ЮKassa от 1 % + НДС; Т-Банк «Мультирасчёты», подключение ≤ 60 дней), ЭДО с физлицами (Контур.Сайн 4 000 ₽/100 документов + НЭП 400–610 ₽; Диадок с бесплатной подписью через Госключ). Горизонт 12 мес.; юридическая проверка (агентская схема, УНЭП в суде) — до разработки.
7. **CRM группы интегрируема:** Битрикс24 REST (2 запр./с, ≈ 172 800/сутки) и amoCRM (7 запр./с на интеграцию, 50/с на аккаунт) с вебхуками — достаточно для канала «партнёр → производство → партнёр» в пилоте.

## 2. Разбор по системам

### 2.1. КАД / «Мой арбитр» / ГАС «Правосудие»
- **Подача:** my.arbitr.ru, вход через ЕСИА без отдельной регистрации; с 01.01.2022 — через Госуслуги или официальную ИС суда (приказ Судебного департамента № 252 от 28.12.2016). Представитель входит под своей учёткой и прикладывает документ о полномочиях; УКЭП обязательна лишь для отдельных документов (обеспечительные меры); с 01.09.2024 представители юрлиц — по МЧД. Публичного API подачи — не найдено. Разработчик КАД и «Мой арбитр» — «ПравоТех»; его «ПравоДела Про» даёт «прямую подачу документов в суд» и вход в онлайн-заседания — единственная найденная частная альтернатива.
- **Отслеживание:** карточка дела публична, но защищена (WASM, `fp.js`; Selenium не работает, живы воспроизведённые запросы к `SearchInstances` — Хабр, 2025). API/RSS — не найдено.
- **Агрегаторы (2026):** ПравоДела — «Стандарт» 6 500 ₽/мес и «Про» 9 000 ₽/мес «при оплате за год»; рядом указаны суммы 78 000 и 108 000 ₽ (страница подписывает их как полугодовые, арифметика даёт годовые — уточнить у вендора); арбитраж, СОЮ, банкротство физлиц, ФССП. Casebook — ≈ 60 000 ₽/польз./год (picktech) или 84 000 ₽/год (kaluga-poisk) — источники расходятся; Casebook API 3.0 (REST: поиск дел, события по делам, банкротствам, ИП) — цена по запросу, 6 подключений (24.10.2024). Обёртки: parser-api.com (200 запросов/мес бесплатно; карточка, поиск по ИНН/ФИО, PDF документов), you-right.ru (КАД + ГАС Правосудие + ФССП + ЕФРСБ + Росреестр: 1 000 — 4 900, 5 000 — 24 000, 10 000 — 46 000, 20 000 — 90 000 ₽/мес; объекты мониторинга не тарифицируются). Caselook — цена не найдена.
- **ГАС «Правосудие»:** ЛК через ЕСИА, подача в СОЮ через Госуслуги с февраля 2024; суперсервис «Правосудие онлайн» (срок 31.12.2024, мировые судьи исключены в 2023) — статус неясен; API не найден. Для БФЛ — редко (судебные приказы, МФЦ-трек).
- **Даёт:** «Подано → Принято / Без движения», заседания, акты об обоснованности, реализации, продлении, завершении — 7–8 состояний из 20; SLA-таймеры по ст. 127 АПК и «без движения».
- **Риски:** парсинг нестабилен и спорен; зависимость от одного вендора (ПравоТех владеет и КАД, и агрегатором); лаг обновления 1–24 ч (оценка).

### 2.2. ЕФРСБ
- **Публикации ФУ** — только ФУ с УКЭП через ЛК или официальный «Сервис передачи реестров, торгов, отчётов и сообщений» (SOAP/XML с подписью, спец. 1.47 — по выдаче); ПАУ загружает опубликованные сообщения и проставляет даты/номера. Производство не публикует (п. 6 ст. 213.9).
- **Чтение:** SOAP с 01.03.2013, REST с 15.04.2024; заявка оператору (АО «Интерфакс»), тест 2 недели, логин/пароль боевого контура; токен, ≤ 8 одновременных запросов с IP; цена не опубликована. Помесячная выгрузка сообщений с 01.01.2011 (download.fedresurs.ru/export_messages). Парсинг — лимит частоты, бан IP на час (Хабр, 07.04.2022). Обёртки: api-assist (200 запросов/мес бесплатно), you-right, Bankro.TECH API (тарифы по запросу). Цена размещения сообщения по новости Федресурса — 902,51 ₽ с НДС (дата новости не установлена; уточняет допущение № 5 плана — проверить в ЛК ФУ).
- **Даёт:** события ФУ без доступа к его ПО → «Реализация введена → Публикации → Торги → Завершено»; внешний контроль срока публикации (3 рабочих дня).
- **Риски:** неизвестная цена REST; поиск по ИНН/СНИЛС требует хранения этих ПДн.

### 2.3. ФССП
- **Официальный API** остановлен письмом ФССП от 22.04.2022 № 00111/22/86665; README архивированного клиента (13.12.2023): «доступ по API остановлен, вопрос о возобновлении не рассматривается»; на 08.09.2026 api-ip.fssp.gov.ru/about — HTTP 410. Исторические лимиты (100/час, 1 000/сутки, 5 000 групповых по 50) — только справочно.
- **Альтернативы:** сайт с капчей; Госуслуги (сведения гражданину, ходатайства); СМЭВ — только «банки, коллекторы, МФО с лицензией» (agredator), с 24.02.2025 обращения взыскателей через СМЭВ/ЕПГУ — не чаще 1 в час. Обёртки: api-parser.ru (без капчи, цены не опубликованы), api-cloud.ru, you-right; ФССП есть в ПравоДела/Casebook.
- **Даёт:** G0-скоринг (перечень ИП, суммы, статус), МФЦ-трек (п. 4 ч. 1 ст. 46). Для SLA — ничего.
- **Риски:** «серый» парсинг; надёжнее выгрузка должника из Госуслуг.

### 2.4. Госуслуги / ЕСИА / Цифровой профиль / Госключ
- **ЕСИА-вход на сайте юрфирмы:** перечень допущенных категорий — банки, страховые, НПФ, брокеры, медорганизации (интегратор mcart, 10.10.2025); нормативный перечень (ПП № 584) не проверен — вопрос юристу. Требования: аттестация ИС, СКЗИ КС3, УЗ.3, OpenID Connect; переход действующих подключений на типовое решение — до 31.12.2026. По данным вендора esia.ru (март 2026): самостоятельно ≈ 5,46 млн ₽ + ≈ 580 тыс. ₽/год, ≈ 1,5 года; через шлюз ≈ 4 мес. **Не для пилота и не для 12 мес.**
- **Цифровой профиль** (ПП № 710, № 1911): кредитные, страховые, МФО, операторы финплатформ, НПФ, операторы связи, ЦФА; с 02.02.2026 REST API отключён, только СМЭВ; тарифы ПП № 1687 — 10 ₽ первичный запрос, 4,93 ₽ повторный (18.12.2025). Юрфирма — вне перечня.
- **Госключ:** бесплатные УНЭП/УКЭП для граждан, с июля 2025 — для руководителей и ИП; интеграция бизнеса — через партнёрский портал Госуслуг (детали не раскрыты) или через оператора ЭДО (Диадок: подпись физлиц через Госключ в API бесплатно).
- **МЧД гражданина** через Госуслуги существует (с 01.02.2026 обязательны СНИЛС, ИНН, дата рождения); применимость для получения справок «за должника» — не подтверждена.

### 2.5. ФНС, СФР, Росреестр, ГИБДД
По практике юрфирм (dvitex, 15.08.2026): 2-НДФЛ — работодатель или ЛК ФНС; выписка СФР и сведения о ТС — Госуслуги; ЕГРН — Росреестр/МФЦ/Госуслуги (третьим лицам без ФИО; полную выписку получают собственник и арбитражный управляющий); справки банков — в каждом банке. API для третьих лиц по данным физлица — не найдено. **Модель:** кабинет должника с инструкцией «какую справку где заказать», загрузка PDF, OCR, автопроверка комплектности.

### 2.6. БКИ
По 218-ФЗ организация с письменного согласия субъекта — пользователь кредитной истории. НБКИ для бизнеса: договор, «код участника», онлайн-сервис и API, «Курс на одобрение» для брокеров и кредитных консультантов; клиенты — банки, МФИ, ломбарды, цессионарии, маркетплейсы, страховые, лизинг «и другие юрлица»; **цены B2B не опубликованы**. ОКБ: скоринг дешевле отчёта, отчёт — гражданину или организации с согласия, помощь с API. Гражданину: 2 отчёта/год бесплатно, далее 500 ₽; через Госуслуги — 2–3 минуты. **Вывод:** пилот и 6 мес. — должник заказывает сам; B2B API — 12 мес. при объёме. Риск: хранение согласий, цель запроса.

### 2.7. Банки: выписки, эквайринг, сплит
- **Выписки:** Открытые API ЦБ (2026 — крупнейшие банки, 2027 — остальные) в октябре 2025 перенесены «до принятия закона», ЦБ надеется на 2027. Агрегаторов для нефинансовых третьих лиц — не найдено. Реалистично: должник выгружает PDF/XLSX из банков → парсер.
- **Сплит:** ЮKassa — одна транзакция нескольким юрлицам, комиссия «от 1 % + НДС» только с успешных платежей, каждый получатель регистрируется отдельно (25.12.2025); «Безопасная сделка» — для C2C. Т-Банк «Мультирасчёты»: безопасная сделка + сплит + номинальный счёт, выплаты юрлицам/физлицам/самозанятым, интеграция бесплатна, комиссия индивидуальная за списание и выплату, подключение ≤ 60 дней; старый сервис «Сплитование» прекращает работу с 01.10.2026 с переводом на Мультирасчёты при сохранении тарифа (справка Т-Банка). Точка — расчёты по номинальному счёту.
- **Даёт:** автоматические вехи 40/30/30 в white-label рассрочке. Депозит ФУ идёт на депозит суда — вне сплита. Договор с должником заключает партнёр → нужна агентская конструкция или прямой договор (юрист до разработки).

### 2.8. ЭДО и подписи
- **Контур.Сайн:** 100 исходящих — 4 000 ₽/год, 200 — 7 000, 500 — 16 500, 1 000 — 31 000 ₽; НЭП на подписанта 610 ₽ (1), 500 (2–10), 450 (11–50), 400 ₽ (51–100); API-лицензия 18 000 ₽/год или 38 000 ₽/5 лет; входящие бесплатны.
- **Диадок:** подключение бесплатно, пакеты от 2 950 ₽/250 документов, API/коннектор от 26 900 ₽, модуль 1С от 6 900 ₽ (по выдаче); Госключ в API — бесплатно для физлиц.
- **Даёт:** договор партнёр ↔ производство и акты по вехам (УКЭП), согласие и поручение на ПДн, уведомления должнику. **Открытый вопрос:** принимает ли арбитражный суд доверенность гражданина с УНЭП через Госключ — по ч. 7 ст. 61 АПК доверенность гражданина удостоверяется нотариально «или в ином установленном законом порядке», практика не найдена → пока нотариальная, офлайн у партнёра.

### 2.9. Почта, курьеры, нотариат
- **Почта России:** otpravka.pochta.ru — API отправлений, партий, калькуляции по договорным тарифам; tracking.pochta.ru — статусы; без договора 100 запросов/сутки (по выдаче); по умолчанию 25 запросов на отправление, суточный лимит калькуляций = 1/3 плановых месячных отправлений (ApiShip). Цена — по договору.
- **СДЭК:** договор → логин/пароль API; **Boxberry:** регистрация юрлица → токен в ЛК; готовые модули для Битрикс/1С.
- **Нотариат:** reestr-dover.ru — бесплатная проверка доверенностей (реестр с 01.07.2014); официальный API — не найден; удалённое удостоверение доверенности — не найдено.
- **Даёт:** трек-номера отправок кредиторам/суду/ФУ → событие «отправлено/вручено».

### 2.10. CRM группы и ПО ФУ
- **Битрикс24 REST:** leaky bucket — 2 запр./с (порог 50), Enterprise 5/с (250); ≈ 172 800/сутки; таймаут 60 с; лимит 420 с/10 мин (HTTP 429); вебхуки на события сделок. **amoCRM:** 7 запр./с на интеграцию, 50/с на аккаунт; вебхуки на смену статуса.
- **ПАУ:** «Лайт» 48 880 ₽/год (1 АУ, 3 места), «Профессионал» 63 880, «Управляющая компания» 240 880 ₽/год, на одного должника 1 000 ₽, техподдержка 35 %; загрузка сообщений ЕФРСБ, экспорт/импорт процедур, экспорт в Excel, «Витрина данных»; публичного API — не найдено. **Bankro.TECH:** регистрация бесплатна, реестр, собрания, задачи, API заявлен, тарифы по запросу.
- **Обмен ФУ ↔ производство без вмешательства:** (а) события ФУ читаются из ЕФРСБ и КАД — источник правды без согласия и интеграции; (б) роль «ФУ» в портале: доступ только к назначенным делам, загрузка досье/описи/реестра по регламенту консорциума, подтверждение событий; (в) добровольный Excel-импорт из ПАУ. Никаких записей в ПО ФУ, общих лицензий и платежей — по «семи правилам» раздела 4.

## 5. Нельзя / нет API — только ручной ввод или действие человека

1. **Подача в «Мой арбитр»** — вручную юристом под ЕСИА; портал хранит входящий номер и квитанцию.
2. **Публикации в ЕФРСБ** — только ФУ с УКЭП.
3. **Официальный API ФССП** — закрыт (410); СМЭВ — не для юрфирм.
4. **ЕСИА-вход и Цифровой профиль** — вне перечня; вход в портал — e-mail/OTP/Telegram.
5. **ФНС, СФР, ЕГРН, ГИБДД по должнику** — только сам должник; ЕГРН третьим лицам — без ФИО.
6. **Банковские выписки** — только от должника.
7. **Кредитный отчёт** — должник сам, пока нет B2B-договора с БКИ.
8. **Нотариальная доверенность на юриста** — офлайн у партнёра; УНЭП для суда не подтверждена.
9. **Депозит ФУ 25 тыс. ₽** — на депозит суда, вне эквайринга.
10. **Заседания и ВКС** — юрист; в портале только дата и результат с документом.
11. **ГАС «Правосудие»** — ручной ЛК.
12. **ПО ФУ (ПАУ/Bankro.TECH)** — не интегрируем по замыслу; только добровольный Excel-импорт.

## 6. Уточнить в фазе 0

- Цена REST ЕФРСБ (Интерфакс) и Casebook API 3.0 — письменные запросы; сравнить с you-right по цене за запрос.
- Актуальность 902,51 ₽ за сообщение ЕФРСБ — проверить в ЛК ФУ (расхождение с допущением № 5 плана).
- Нормативный перечень допущенных к ЕСИА (ПП № 584) — юрист; ожидаемый ответ «нет».
- УНЭП/Госключ для доверенностей в арбитражном суде и договора с должником — заключение + пробная подача.
- Схема сплита (агент / номинальный счёт) при договоре должника с партнёром — юрист + менеджер Т-Банка/ЮKassa.
- Есть ли у Casebook/ПравоДела мониторинг физлиц по ИНН/СНИЛС в нужном объёме и какой лаг.
- Условия и цена B2B-отчётов НБКИ/ОКБ для юрлица-пользователя КИ без статуса кредитора.
