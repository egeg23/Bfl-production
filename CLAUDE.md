# BFL Production — контрактное юридическое производство БФЛ

Репозиторий проекта «внешнее юридическое производство по банкротству физических лиц (БФЛ)
для юридических компаний-партнёров» — B2B-продукт, запускаемый при СРО арбитражных
управляющих «ПроРешения» (sro-proresheniya.ru). Роль пользователя: руководитель продукта /
лидер проекта (вакансия «Лидер проекта / CEO проекта»).

Это НЕ часть seller-ai и других репозиториев пользователя — самостоятельный проект.

## Что здесь лежит

- `README.md` — краткое описание проекта и навигация
- `docs/PLAN.md` — **главный документ**: план запуска продукта (бизнес-модель, производственный
  контур, финмодель, консорциум, дорожная карта, пилот, KPI, риски, команда, IT-контур, 30/60/90)
- `docs/VACANCY.md` — исходное описание роли и продукта от работодателя (копия Google Doc)
- `docs/SOURCES.md` — источники (URL) для всех фактов и цифр плана
- `docs/research/` — отчёты исследования по направлениям (компания, 127-ФЗ и процесс, рынок и
  конкуренты, бизнес-модели, IT-архитектура, наработки пользователя, найм/собеседование)

## House rules

- Русский — для документов, планов и общения; английский — для кода, имён файлов, коммитов
- Никаких секретов в репозитории (токены, пароли, ПДн должников) — только в `.env` (gitignored)
- Цифры в документах — со ссылкой на источник или пометкой «оценка/допущение»
- Данные должников (ПДн) в этот репозиторий не попадают никогда — даже в примерах
- При изменении плана обновлять раздел «Журнал изменений» в `docs/PLAN.md`

## Стартовая фраза для новой сессии

«Продолжаем BFL Production — читай `docs/PLAN.md`» — дальше по разделу «Следующие шаги».
